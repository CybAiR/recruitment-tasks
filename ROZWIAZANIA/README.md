## Zakres weryfikacji

W dniu 21 listopada 2026 r. przeprowadzono automatyczne
testy rozwiązań zadania Level 2 (UART -> ROS 2)
w środowisku Docker z ROS 2 Jazzy.

Wszyscy trzej uczestnicy zaliczyli testy CORE i STRESS.

Formalna weryfikacja obejmowała wyłącznie plik
`serial_bridge_node.py` każdego uczestnika.

Dodatkowy symulator Dominika oraz rozwiązanie Level 3
Igora nie były przedmiotem formalnej oceny.
